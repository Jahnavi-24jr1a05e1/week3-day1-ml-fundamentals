1. What is the slope?

The slope is represented by the coefficients of the Linear Regression model. Each coefficient shows how much the predicted marks change when a feature increases by one unit while keeping other features constant.

2. What is the intercept?

The intercept is the starting value of the prediction when all feature values are zero.

3. What do they mean?

The coefficients indicate the importance and impact of each feature on student marks. The intercept acts as the baseline prediction. Together they form the regression equation used for predictions.

Part 10 — Student Research Activity

1. What is Machine Learning?

Machine Learning is a branch of Artificial Intelligence (AI) that enables computers to learn from data and make decisions or predictions without being explicitly programmed for every task. Instead of following fixed instructions, machine learning systems identify patterns in data and use those patterns to improve their performance over time. Machine learning is widely used in modern technology because it can analyze large amounts of data quickly and accurately. There are different types of machine learning, including supervised learning, unsupervised learning, and reinforcement learning. In supervised learning, the model is trained using labeled data, while unsupervised learning finds patterns in unlabeled data. Machine learning is useful because it can automate complex tasks, reduce human effort, and provide valuable insights from data. Examples include recommendation systems, spam email detection, image recognition, speech recognition, and self-driving cars. As data continues to grow rapidly, machine learning plays an increasingly important role in solving real-world problems across various industries.

2. What is Linear Regression?

Linear Regression is one of the simplest and most widely used machine learning algorithms. It is a supervised learning technique used to predict continuous numerical values. The algorithm establishes a relationship between one or more input variables, known as features, and an output variable, known as the target or label. Linear Regression works by fitting a straight line through the data points in such a way that the prediction errors are minimized. The equation of a linear regression model consists of coefficients and an intercept. These values determine how strongly each feature affects the target variable. Linear Regression is commonly used in business, finance, education, and healthcare for forecasting and trend analysis. For example, it can predict house prices, student marks, sales revenue, or employee salaries. Because of its simplicity and interpretability, Linear Regression is often the first algorithm learned by students and data scientists when studying machine learning. It serves as a foundation for understanding more advanced predictive models.

3. What are Features?

Features are the input variables used by a machine learning model to make predictions. They represent the information or characteristics that help the model understand patterns in the data. Features can be numerical, categorical, or even text-based depending on the type of dataset being analyzed. In a student performance dataset, examples of features include Study Hours, Attendance, and Assignments completed. These variables provide information about a student's learning habits and academic engagement. The quality and relevance of features directly affect the performance of a machine learning model. Selecting useful features helps improve prediction accuracy, while irrelevant features may reduce model effectiveness. Feature engineering is the process of creating, transforming, or selecting the most important features from raw data. Machine learning algorithms use these features to learn relationships and generate predictions. Features are important because they act as the foundation of the learning process. Without meaningful features, even the most advanced machine learning algorithms may fail to produce accurate results.

4. What are Labels?

Labels are the output values that a machine learning model tries to predict. In supervised learning, labels are already known and are used to train the model. The model learns the relationship between the features and the labels so that it can make predictions for new data. Labels are sometimes called target variables or dependent variables. In the student performance dataset, Marks is the label because it is the value being predicted using Study Hours, Attendance, and Assignments. Labels can be numerical values, categories, or classes depending on the problem being solved. For example, in a house price prediction problem, the label is the house price. In an email spam detection system, the label may be Spam or Not Spam. Accurate labels are essential because they guide the learning process and help the model understand what it should predict. Without labels, supervised machine learning models cannot be trained effectively. Labels play a critical role in evaluating model performance and prediction accuracy.

5. What is the Difference Between Training Data and Testing Data?

Training data and testing data are two important parts of a machine learning workflow. Training data is the portion of the dataset used to teach the machine learning model. During training, the model analyzes patterns and relationships between features and labels. The goal is to learn how the inputs influence the outputs. Testing data, on the other hand, is used to evaluate the model after training. The testing dataset contains data that the model has not seen before. This helps determine how well the model performs on new and unseen information. Splitting data into training and testing sets prevents overfitting, which occurs when a model memorizes the training data instead of learning general patterns. A common split is 80% training data and 20% testing data. Good performance on testing data indicates that the model can generalize well to real-world situations. Both training and testing datasets are essential for building reliable and accurate machine learning models.

6. Where is Machine Learning Used in Real Life?

Machine Learning is used in many areas of everyday life and has become an important part of modern technology. One common application is recommendation systems used by streaming platforms and online shopping websites to suggest movies, songs, and products. Machine learning is also used in healthcare to help doctors diagnose diseases, analyze medical images, and predict patient outcomes. In finance, it helps detect fraud, assess risks, and automate trading decisions. Social media platforms use machine learning to personalize content and improve user experiences. Voice assistants such as Siri, Alexa, and Google Assistant rely on machine learning for speech recognition and natural language understanding. Self-driving cars use machine learning to recognize roads, traffic signs, and obstacles. Educational platforms use machine learning to provide personalized learning experiences for students. Businesses use predictive analytics to forecast sales and customer behavior. As technology continues to advance, machine learning is becoming increasingly important in solving complex problems and improving efficiency across industries.

Bonus Challenge – Salary Prediction

For the bonus challenge, a Salary Prediction dataset was created with 20 records. The dataset contains three features: Experience, Education Level, and Projects Completed. The target variable is Salary.

The model was evaluated using Mean Absolute Error (MAE) and R² Score. A Plotly scatter chart was created to visualize the relationship between experience and salary. The results showed that salary generally increases with experience, education level, and project involvement.
