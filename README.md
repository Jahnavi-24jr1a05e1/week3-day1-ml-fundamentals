# Week 3 Day 1 – Machine Learning Fundamentals

This project demonstrates the complete machine learning workflow using Python, Pandas, Scikit-learn, and Plotly. The objective of the project is to build a predictive model that estimates student marks based on study hours, attendance percentage, and assignment completion.

The dataset contains information about students and their academic performance. Initially, the dataset was explored using various Pandas functions to understand its structure, columns, and statistical properties. Features and labels were identified, and the data was divided into training and testing sets using an 80-20 split.

A Linear Regression model was trained using Scikit-learn. After training, predictions were generated for both testing data and new student records. Model performance was evaluated using Mean Absolute Error (MAE) and R² Score, which help measure prediction accuracy and model effectiveness.

Several interactive visualizations were created using Plotly, including scatter plots and regression line charts. These visualizations help understand relationships between study habits and student marks.

This project provides a strong foundation in machine learning concepts such as data preparation, model training, evaluation, visualization, and prediction.
